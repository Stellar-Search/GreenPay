# Project instructions for Claude Code

## Naming conventions

Do not use AI/model-related terms (e.g. `claude`, `anthropic`, `ai`, `bot`, `copilot`, `assistant`) in anything committed to this repository:

- Branch names you create yourself
- Commit messages
- Pull request titles and descriptions
- File and directory names
- Code identifiers (variables, functions, classes)
- Code comments

Use plain, descriptive names based on the work being done instead (e.g. `sync/upstream-main`, `fix/donation-race-condition`).

Note: this cannot control the branch name a session harness assigns automatically when a task is created (e.g. via Claude Code on the web) — that name is set before the repo is visible to these instructions. If a designated session branch has an AI-related name, ask the operator whether to push the work to a renamed branch instead once the task is otherwise complete.
